How it works

FAQ

Common questions

How often is the data refreshed?

Job listing data is updated weekly via nightly scrape runs. HTTP header data is re-checked weekly. Change events are logged on every scrape so you can see when a company added or removed a technology.

How many companies are in the database?

We currently have 230+ companies indexed and are adding more every week. Enterprise customers can request specific companies be added to the scrape list.

What's the confidence score?

Every technology signal has a confidence score from 0 to 1. HTTP headers score 0.92–0.95 (direct evidence). Job listing mentions score 0.70. When multiple sources agree, the score is boosted up to 0.99.

How are API keys issued?

After subscribing, you'll receive your API key via email within 24 hours. Use it in the Authorization header: Authorization: Bearer your_key

Can I try it before paying?

Yes — email us and we'll set up a 7-day trial key with 100 requests. No credit card required.

Is this different from BuiltWith or Wappalyzer?

Yes. BuiltWith focuses on front-end tech from website fingerprinting. We index back-end infrastructure, data tools, and cloud providers inferred from job listings — signals that BuiltWith can't detect. And we're 10x cheaper.
